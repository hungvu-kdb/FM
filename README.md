# Analytic
## Mathematical model

Measured robust aggregate (46 samples):

```text
(cx,cy)       = (130.0, 154.5) px
(hx,hy)       = (111.5, 138.0) px
r             = 5.25 px
w             = 1.0 px
a_content, f  = 255.0, 1.0
g, s, k       = 9.0 px, 3.0 px, 72.092695
```

The sample center and bounds were invariant. The fitted corner-radius median is `5.25`; sample fits span `4.75..6.0`. The halo peak scalar is a least-squares parameter over radial medians, so it need not equal the raw scanline maximum at a single raster distance.

For pixel centre `p=(x,y)`, center `c=(cx,cy)`, half-size `h=(hx,hy)`, and corner radius `r`, define:

```text
q = abs(p-c) - (h-r)
d(p) = length(max(q,0)) + min(max(q.x,q.y),0) - r
```

`d<0` is inside the rounded rectangle. Analytical edge coverage is

```text
C(p) = clamp(0.5 - d(p)/w, 0, 1)
```

where `w` is edge softness. With alpha floor `f`, detached gap `g`, halo peak `k`, and Gaussian sigma `s`, the exterior-only halo is

```text
H(p) = f                                      if d(p) < g
       f + (k-f) exp(-0.5 ((d(p)-g)/s)^2)     if d(p) >= g
```

For analysis (an opaque source), generated alpha is

```text
A_model(p) = max(a_content C(p), H(p)).
```

For an RGBA portrait with source alpha `A_src`, application uses

```text
A_out(p) = max(a_content C(p) A_src(p)/255, H(p)).
RGB_out(p) = RGB_src(p) when C(p)>0, else black.
```

Thus transparent source pixels remain transparent in content, partially transparent source pixels retain that alpha, and halo RGB is black. RGB uses straight-alpha storage.

## Assumptions and limitations

The shared frame is treated as symmetric and generated by one rounded rectangle. The halo is a compact one-sided Gaussian with a hard inner cutoff, not an arbitrary blur texture. Pixel-level encoder/antialias differences and any sample-specific alpha defects are deliberately not represented. Median aggregation protects the model from those outliers but cannot reproduce every source pixel exactly.

## Validation

Over every alpha pixel in all 46 samples, the analytical model obtains MAE `1.433060`. Absolute-error percentiles are p50 `0`, p75 `0`, p90 `2.798910`, p95 `6.762470`, p99 `25.887878`, and p99.9 `99`. Per-image MAE ranges `1.350232..1.810454` with median `1.436951`. These metrics compare each observed source alpha directly with one alpha field rendered from the robustly aggregated scalars.

Unlike MVP1's fixed mean-alpha matrix and `template == 255` mask, MVP2 serializes only the 13 numeric scalar fields in `model.json`. `generated_alpha.png` is validation output, not an application input; `apply_frame.py` reconstructs all coverage from the equations above.
